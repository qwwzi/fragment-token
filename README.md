# Fragment Token

一个简单的 Chrome 扩展：读取当前浏览器里 fragment.com 的 `Token`，方便快速拿到登录后的 Token以及登录

## 安装方法（开发者模式加载）

1. 解压这个压缩包
2. Chrome/Edge浏览器 打开 `管理扩展`
3. 打开右上角「开发者模式」
4. 点击「加载已解压的扩展程序」，选择解压后的文件夹

## 使用方法

1. 登录 fragment.com 后，点击工具栏里的插件图标
2. 面板会显示当前的 `Token`

也可以在「通过 Token 登录」区域粘贴已有 Token，点击「登录并刷新」。扩展只会将 Token 写入本机的 fragment.com Cookie，不会保存到扩展存储或上传到服务器。

## 注意事项

- 插件只在你主动点击图标或刷新时读取 `Token`，不会在后台常驻运行，也不会把数据发送到任何服务器，所有内容只停留在你本机
- 请遵守 fragment.com / Telegram 的服务条款，仅用于个人合法用途
